READ BEFORE DOWNLOADING!

Do NOT download this on your computer. Download this on the Worker Drone.

Steps to download:

1. Customize the WDSYS to fit your character. For more steps on this, go to the next step page.

2. Package the WDSYS into a .iso

3. Put the .iso on a USB/CD

4. Open the hatch to the computer access, and plug the USB/CD in.

5. Wait for the setup to complete.

6. When completed, turn off the system, unplug the USB/CD, and start it up.

7. There ya go!

Steps to customize:

1. Download the repo "WDSYS resources"

2. Grab all the assets that you want, and follow these steps carefully.

3. If you are doing the gui, carefully move the preset faces to the resources folder in WDSYS\gui\face.

4. If you are doing PAPIK (personality API key), carefully replace the c_ai_talk.exe with your new one.

5. There ya go! once you are ready, go to the second step in "Steps to download"
